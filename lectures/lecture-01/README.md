# Lecture 01 - Introduction

Welcome to DATASCI 350! This first lecture introduces the course, shows you why data science computing is worth learning, and explains how everything will work.

[View the slides](https://danilofreire.github.io/datasci350/lectures/lecture-01/01-introduction.html)

## What we cover

- Who I am, how the course runs, office hours, and what to expect in class
- Why data science matters: the growth of digital data, and what researchers do with it
- The three themes of the course: reliability, reproducibility, and robustness
- The tools you will learn to use
- Assessment, deadlines, and the software you need to install

## Tools you will meet

Command line and bash; Git and GitHub; AI coding agents (GitHub Copilot, Claude Code, Gemini CLI, and Codex CLI); Quarto and Jupyter; `requests` and Beautiful Soup; pandas, SQLite, DuckDB, and Dask; uv and Docker. You do not need to know any of these yet.
