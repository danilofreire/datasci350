# Lecture 02 - Computational Literacy

How computers store everything, from a number to a photograph, using nothing but 0s and 1s.

[View the slides](https://danilofreire.github.io/datasci350/lectures/lecture-02/02-computational-literacy.html)

## What we cover

- A short history of computing, from the abacus to the transistor
- The Von Neumann architecture, which almost every computer still follows
- Binary and hexadecimal, and how to convert between them and decimal
- ASCII and Unicode, and how text becomes numbers
- Konrad Zuse, assembly language, and why high-level languages exist

## Practice

The deck has four sets of exercises: coin conversions, decimal to binary, binary to hexadecimal, and decoding ASCII. Each one has a Solutions button that jumps to the worked answer, and a button to jump back. Try them before looking.
