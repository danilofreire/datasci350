# Lecture 05 - Git and GitHub

How to organise a project, and how to keep every version of it without ever naming a file `final_v3_REALLY_final`.

[View the slides](https://danilofreire.github.io/datasci350/lectures/lecture-05/05-git-github.html)

## What we cover

- Thinking in projects: what goes in a project folder, and how to lay it out
- Naming and numbering your scripts so they run in a sensible order
- What version control is, and the problems it solves
- Git and GitHub, and why they are not the same thing
- Repositories, working directories, the staging area, and commits
- `git init`, `git add`, `git commit`, `git status`, `git log`, and `git checkout`

## Follow along

We build a repository together in class. Keep the `my-project` folder you create, because we use it again next time. If you fall behind, the slides show every command with its output beside it.

The commit hash on the `git checkout` slide is from my machine. Copy yours from `git log`, where the first seven characters are enough.

## Before the next class

1. Install Git from [git-scm.com](https://git-scm.com/downloads).
2. Create a GitHub account with your Emory email address.
3. Apply for the [Student Developer Pack](https://education.github.com/pack), which gives you GitHub Pro and Copilot for free.
4. Run `git config --global user.name` and `git config --global user.email` to introduce yourself to Git.
